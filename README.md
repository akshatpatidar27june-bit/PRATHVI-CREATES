# PRATHVI CREATES

A cinematic, responsive portfolio website for Prathvi Creates.

## Run locally

This is a lightweight static website. No build step or package installation is required.

1. Download or clone the repository.
2. Open `index.html` in a modern browser, or run a local static server:
   ```bash
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000`.

## Included

- Responsive portfolio layout
- Interactive Three.js 3D hero (loaded from jsDelivr)
- Scroll reveal effects, custom pointer treatment, mobile navigation
- Work, services, process, about and contact sections
- Email and Instagram contact links

## Before publishing

The four artwork cards in the Selected Visuals section are designed placeholders. Replace them with Prathvi's actual video thumbnails, project names, and reel/showreel links. The About copy and experience duration are based on the supplied brief. Check all details and add real work samples before sharing the site publicly.
